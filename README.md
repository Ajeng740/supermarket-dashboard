# Supermarket Sales Dashboard

Dashboard analisis data penjualan supermarket menggunakan Python dan Streamlit.

Project ini dibuat untuk mengolah dan menganalisis data penjualan supermarket sehingga dapat memberikan informasi mengenai pola penjualan, performa produk, perilaku customer, dan wilayah dengan penjualan tertinggi.

## Preview Dashboard

Dashboard memiliki beberapa fitur analisis untuk membantu melihat informasi penjualan secara interaktif.

## Features

### 1. Overview Dashboard
- Menampilkan total sales
- Menampilkan jumlah order
- Menampilkan jumlah customer
- Menghitung rata-rata nilai order
- Melihat trend penjualan berdasarkan waktu
- Menampilkan preview dataset

### 2. Sales Analysis
- Filter data berdasarkan periode tanggal
- Filter berdasarkan kategori produk
- Analisis total sales berdasarkan kategori
- Analisis sales berdasarkan sub-category
- Grafik trend penjualan bulanan

### 3. Product Analysis
- Menampilkan 10 produk dengan penjualan tertinggi
- Melihat performa produk berdasarkan total sales

### 4. Customer Analysis
- Menampilkan customer dengan pembelian tertinggi
- Analisis penjualan berdasarkan segment customer:
  - Consumer
  - Corporate
  - Home Office

### 5. Region Analysis
- Analisis penjualan berdasarkan wilayah
- Menampilkan 10 kota dengan total sales tertinggi

## Tools & Technologies

- Python
- Pandas
- Streamlit
- Matplotlib

## Dataset

Dataset yang digunakan adalah data penjualan supermarket yang berisi informasi transaksi, customer, produk, kategori, wilayah, dan tanggal pemesanan.

Kolom yang digunakan:
- Order ID
- Order Date
- Customer Name
- Segment
- City
- Region
- Category
- Sub-Category
- Product Name
- Sales
